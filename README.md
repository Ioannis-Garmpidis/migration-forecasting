## 🛠️ Setup Instructions

### Notebook (Google Colab)

1. Upload `Predictive_analysis.ipynb` to Google Colab
2. Connect to Google Drive
3. Place all data files (`xlsx`, `.nc`) in your Google Drive root folder
4. Run all cells sequentially

> ⚠️ Full execution takes several hours due to GDELT data volume (~49GB). Intermediate results are saved automatically as Parquet files in Google Drive.

### Dashboard (Local)

1. Place the following files in a folder called `Dashboard`:
   - `app.py`
   - `dashboard_table.csv`
   - `drivers_importance.csv`
   - `forecast_monthly.csv`
   - `gdelt_visuals_route_month.parquet` (generated by the notebook)

2. Install dependencies:

```bash
pip install streamlit plotly pandas pyarrow
```

3. Run:

```bash
cd Dashboard
streamlit run app.py
```

4. Open your browser at `http://localhost:8501`
